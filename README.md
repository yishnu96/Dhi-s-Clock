# Dhi’s Clock

A fast, accessible two-page site for Dhi’s Clock, Saudamini Mishra’s work and writing.

## Local development

Use Node.js 24 (selected in `.nvmrc` and CI); React and React DOM render the new media sections during the build; no React bundle is sent to visitors.

```powershell
npm ci --ignore-scripts
npm run check
npm run build
npm run dev
```

The preview server listens on `http://localhost:4173` by default. Set `PORT` to choose another port. It serves the source tree for editing. The build writes a production-ready static site to `dist/`.

## Build output

Repository housekeeping is included: `.gitignore` excludes generated output, dependencies, local environment files and caches; `.editorconfig` and `.gitattributes` keep formatting and line endings consistent. `package-lock.json` records the npm project state. GitHub Actions runs the build and validation on pushes and pull requests; it does not deploy.

`dist/` was already tracked before `.gitignore` was added. Existing tracked files remain tracked; the ignore rule applies to new untracked files. Deployments always regenerate `dist/` from source.

`npm run build` copies the two pages, shared styles and script, web manifest, robots and sitemap files, production web fonts and WebP assets, and selected client media under `assets/client/`. It intentionally omits source photography, design documents, tooling and unused original image formats. Deploy the contents of `dist/` to any static host. The included Netlify configuration builds and publishes that directory.

`npm run check` checks page metadata and canonical URLs, JSON-LD syntax, image alt attributes, local links and fragments, the sitemap, and web manifest. Run it again after editing either page or changing asset paths.

## Search engines

The canonical host is `https://www.dhisclock.com`. Configure the hosting provider to redirect alternate host and HTTP traffic to that HTTPS host. After the domain is serving the final build, verify domain ownership in Google Search Console, then submit `https://www.dhisclock.com/sitemap.xml`. Verification and sitemap submission require access to the owner’s Search Console property; they are not part of this repository build.

## Editing the site

Edit content/layout in `tools/render-pages.mjs`, media descriptions in `assets/client/manifest.json`, styling in `styles.css`/`tokens.css`, and interactions in `app.js`. `index.html` and `about.html` are generated files and are regenerated by `npm run build`.

The campaign gallery is currently hidden by request. The theme starts automatically from local time (06:00–17:59 light); the toggle changes to the opposite mode and retains the choice for this browser session. The single button always names the next action: Dark mode or Light mode.

`node tools/smoke.mjs http://127.0.0.1:4174` performs read-only HTTP checks against a running local production preview. See `docs/verification.md` for completed checks and external publishing steps.

## Reviewed media

The November media additions are catalogued in `assets/client/new/media.json`; `tools/media-placement.mjs` defines their page, order and headings. `tools/media-sections.mjs` renders these as React components at build time. The audit in `docs/media-audit-2026-11-07.md` records source evidence and duplicates. Edit these source files rather than generated HTML.
